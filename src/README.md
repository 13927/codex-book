# 引言

这是一本剖析 **Codex**（OpenAI 的本地编码 agent）的中文电子书。我们不满足于"会用"，
而是逐层拆开它的外壳：技术细节、具体实现、整体架构、技术难点——并在每一章的最后，
把 Codex 的设计放回到通用 agent 的理论坐标系里，看看它与业界通行做法的异同。

## 这本书适合谁

- 想搞清楚"一个工业级编码 agent 到底是怎么造出来的"的开发者；
- 正在使用或集成 Codex（TUI、IDE 扩展、SDK、app-server），想理解其行为边界的用户；
- 在设计自己的 agent 系统，想参考一份真实工程取舍的架构师。

## 怎么读这本书

每章固定六段式结构，支持两种读法：

| 小节             | 内容                                       | 适合            |
| ---------------- | ------------------------------------------ | --------------- |
| 本章导读         | 学习目标与前置章节                         | 所有读者        |
| 概念与架构       | 用类比和图讲清 what/why，**不出现代码**    | 所有读者        |
| 源码深挖         | 关键文件、调用链、数据结构，引用精确到行   | 想下潜的读者    |
| 技术难点与设计取舍 | 这个子系统最难的问题与 Codex 的解法      | 想下潜的读者    |
| 对照通用 agent 范式 | 映射到 ReAct、上下文工程等通用概念      | 想下潜的读者    |
| 小结与下一章预告 | 要点回顾                                   | 所有读者        |

**新手路线**：只读每章的「本章导读」「概念与架构」「小结」，即可获得一条完整、
连贯的主线叙事。**进阶路线**：六个小节全读，并对照仓库源码验证引用。

## 阅读路径

全书按认知曲线分五个部分，由浅入深：

1. **认识 Codex** — 建立全局直觉：它是什么、代码怎么逛、先跑起来；
2. **看懂一次请求** — 主干链路：谁和谁通信、一条消息的完整旅程；
3. **Agent 的大脑** — 核心机制：线程模型、采样流式、上下文压缩、持久化；
4. **Agent 的手和脚** — 执行与安全：工具系统、审批沙箱、MCP；
5. **形态与进阶** — 前端与服务化：TUI 内部、headless 模式、app-server 架构。
